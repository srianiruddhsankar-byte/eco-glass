Abyssal Glass — biomimetic biophotonic fiber

A biophotonic optical fiber grown at room temperature from deep-sea glass sponge biology (Euplectella aspergillum), tested against real subsea cable conditions using rules drawn from peer-reviewed literature rather than assumption.

The idea in short

Conventional optical fiber requires melting ultra-pure silica at ~2000°C, and rigid quartz is prone to catastrophic micro-fracture. The sponge Euplectella aspergillum grows concentric silica spicules at 4°C using the enzyme silicatein, with thin organic interlayers that deflect cracks instead of letting them propagate. This project translates that mechanism into a lab-stage optical fiber design, and this site is the interactive test model — not a claim that the physical fiber has been built.

Fiber lab →

Rotate and inspect the 8-layer fiber core in 3D, swap materials per layer, run crack-deflection tests against a quartz baseline, and work through the Group B validation experiments with literature citations.

Cable lab →

Rotate and inspect the full 8-layer subsea cable assembly in 3D, run anchor strike / pressure / abrasion tests against the armor rule set, independent of the fiber core inside it.

How this was built

Both labs use real WebGL 3D (Three.js) — the models are draggable and zoomable, not flat images. Every rule the test engine follows is tagged with the paper it's drawn from; click a citation tag in either lab to see the source. Static files only — open directly in a browser, or drop into a repo and deploy anywhere that serves static HTML.
